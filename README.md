# CodeVault

本地优先的 LeetCode 算法知识管理 Chrome 扩展。v0.2 Round 1–6 的开发与受控回归已完成，正在等待最终用户验收；安装包版本暂保留 `0.1.0`，不替代历史 Git 标签 `v0.1.0`。

## 使用流程

1. 打开 LeetCode，点击右下角 `</>` 按钮进入收藏题库。支持按题名、标签、解法名称搜索，点击收藏跳转到题目。
2. 点击“查看当前题目”，或在编辑器/标准题解代码块悬停后选择“添加至 CodeVault”。读取快照后保存解法，名称留空自动命名。
3. 从解法列表“加载到编辑器”。覆盖不同内容前需确认，加载后可 Ctrl+Z 撤销；代码语言需与网页编辑器一致。
4. 笔记直接输入普通文字，粘贴、拖入或上传图片后原位显示；停止输入750ms后自动保存。图片删除需确认，十秒内可撤销。
5. 设置中选择 DeepSeek、OpenAI 或 Anthropic Claude，输入 Key、选择模型、测试并保存。自定义兼容接口放在高级设置。
6. 在 AI 区选择已保存解法或当前编辑器，读取摘要后主动发送，流式查看 Markdown 分析。完整结果可保存到对应解法；临时编辑器分析需先保存解法再选择分析。停止、失败或截断的结果不能保存。
7. 顶部返回按钮回到题库，保留搜索与滚动位置；长详情滚动时导航始终可用。

两站同一题共用收藏、解法与笔记。支持普通 `/problems/<slug>/` 题目及标准题解代码块，不支持竞赛专用路径、所有非标准编辑器或文章组件。不会运行代码或判定 AC。

## 数据和边界

- 数据保存在当前浏览器配置文件的扩展 IndexedDB，主数据库 v5 原地迁移旧记录，保留旧笔记原文与附件备份。重新加载扩展保留已保存数据。
- 解法代码和语言是不可变快照；修改代码需保存新版本。元数据、分析与笔记写入检查版本，冲突不覆盖其他会话。
- 笔记上限20000字符；PNG/JPEG/WebP 每次一张，单张输入及转换后的 PNG 上限2MB，每篇最多5张/6MB。不加载外部图片。
- 自动保存失败保留当前页面会话的草稿；存储故障、强制关闭进程后的未提交草稿不承诺恢复。
- Key 本地未加密保存、不回显、不云同步；只向所选服务商发起用户主动的连接测试或分析，可能产生费用。分析发送题目信息、语言与代码，不发送笔记或图片。
- AI 分析最多50000字符代码、25秒超时，需支持流式响应；Markdown 不执行 HTML 或加载外部图片。150至300字是提示词目标，不是实际模型输出保证。
- 暂无题目删除、数据导出、云同步和解法删除撤销；解法删除需确认且永久，图片删除可短时撤销。

## 开发与安装

需要 Node.js 22.12+。依赖由 package-lock.json 锁定。

```powershell
npm ci
npm run build
```

在 Chrome 的 `chrome://extensions`（或 Edge 扩展页）开启开发者模式，加载已解压扩展，选择 `dist`。更新代码后重新构建、重新加载扩展并刷新 LeetCode 页面。

`npm run dev` 可预览 `/popup.html`、`/options.html`；实际扩展功能使用生产构建。

## 验证

```powershell
$env:CODEVAULT_BROWSER_CHANNEL = 'msedge'
npm test
```

默认测试包含类型检查、生产构建和26项自动化测试。使用独立浏览器配置、受控网页、真实 IndexedDB 和模拟 AI；截图位于忽略跟踪的 `test-results/`。覆盖双站导航、代码捕获与加载、数据迁移/回滚/离线恢复、图文笔记和 AI 流式保存，不消耗真实 API 额度。

```powershell
$env:CODEVAULT_LIVE_HOST = 'leetcode.cn'
npm run test:live
```

实站检查使用临时浏览器配置，验证识别、收藏、编辑器保存/加载/Ctrl+Z、图文笔记保存和返回题库；不提交或运行代码。国际站可设置为 `leetcode.com`，省略则顺序检查两站。网络和人机验证可能导致失败。

本轮结果及尚待人工验收项见 [v0.2 验收记录](docs/ACCEPTANCE_v0.2.md)。真实付费 AI、系统剪贴板、国际站完整编辑器流程尚未最终验收。

## 目录

- `src/content`：Shadow DOM 面板、笔记与 AI 界面。
- `src/components`：共享题库、品牌与视觉样式。
- `src/popup`、`src/options`：扩展页。
- `src/background`：消息、导航与存储入口。
- `src/editor`、`src/platforms`：Monaco 桥接、LeetCode 和文章适配器。
- `src/database`：IndexedDB、迁移、校验和客户端。
- `src/ai`：服务商、配置、流式解析和请求取消。
- `docs`：需求、架构、设计和验收记录。
