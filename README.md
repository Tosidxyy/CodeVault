<h1 align="center">CodeVault</h1>

<p align="center">收藏题目，积累解法，留下自己的思考。</p>

CodeVault 是一个本地优先的 LeetCode 算法知识管理浏览器扩展，帮助你保存解法、记录思路，并在复习时回到自己的代码和笔记。

当前版本：**v0.2.0**。支持 LeetCode 中文站与国际站，可在 Chrome 或 Edge 中使用。

## 功能

- **收藏题库**：保存题目信息，按题名、标签和解法名称搜索，快速打开收藏与最近访问的题目。
- **多版本解法**：保存编辑器代码或标准题解代码块，记录名称、语言、来源和备注。
- **加载历史代码**：将同题、同语言的解法加载回编辑器，覆盖前确认，支持 Ctrl+Z 撤销。
- **图文笔记**：一个思路输入框，支持上传、粘贴和拖入图片；自动保存、缩略图浏览、点击放大及图片删除撤销。
- **可选 AI 分析**：使用自己的 API Key 分析代码思路、复杂度和易错点，流式查看结果，并将完整分析保存到解法。

## 安装

目前可通过本地加载安装。需要 Node.js 22.12 或更高版本。

```sh
git clone https://github.com/Tosidxyy/CodeVault.git
cd CodeVault
npm ci
npm run build
```

1. 在 Chrome 打开 `chrome://extensions`，或在 Edge 打开 `edge://extensions`。
2. 开启“开发者模式”，点击“加载已解压的扩展”。
3. 选择项目构建生成的 `dist` 文件夹。
4. 打开或刷新 LeetCode 页面，即可使用。

如果已有发布 ZIP，先解压，再选择包含 `manifest.json` 的文件夹加载。更新本地扩展后，在扩展管理页点击重新加载，并刷新 LeetCode 页面。

## 使用

### 收藏与保存解法

打开 LeetCode 普通题目页，点击右下角 CodeVault 图标，选择“查看当前题目”并收藏。鼠标悬停在编辑器或标准题解代码块上，点击“添加至 CodeVault”，保存代码快照；名称留空时会自动命名。

工具栏图标也可打开收藏题库。通过搜索找到题目，点击即可跳转；同一题在中文站和国际站共用收藏、解法与笔记。

### 加载历史解法

先将网页编辑器切换到与解法一致的语言，再点击该解法的“加载到编辑器”。当前代码与保存版本不同时，需要确认覆盖。加载成功后可按 Ctrl+Z 恢复原代码。修改代码后保存为新的解法版本。

### 记录图文笔记

在笔记框记录思路和易错点，停止输入后自动保存，确认显示“已保存”。图片可以上传、粘贴或拖入，排列在文字框下方；点击缩略图可放大，悬停显示删除 ×，删除后十秒内可撤销。

支持 PNG、JPEG 和 WebP。每题最多五张图片、合计6MB，单张输入及转换后的图片不超过2MB；文字最多20000字符。

### 使用 AI

进入设置，选择 DeepSeek、OpenAI、Anthropic Claude，或配置自定义兼容 HTTPS 接口。输入自己的 API Key 并选择模型，按需测试连接，然后授权并保存。

在题目详情选择已保存解法或当前编辑器作为分析对象，读取代码摘要后主动发送。完整结果可保存到选中的解法；当前编辑器的临时分析如需保存，请先保存解法，再选择它进行分析。停止、失败或不完整的结果不能保存。

AI 服务需要用户自己的账户和额度，测试连接与分析可能产生服务商费用。AI 输出仅供学习参考，CodeVault 不运行代码、不自动提交，也不判定代码是否通过测试。

## 数据与隐私

题目、解法、笔记、图片和已保存的分析保存在当前浏览器本地，不提供 CodeVault 云同步。API Key 也保存在本地，当前没有额外的静态加密。

只有用户主动测试或发送分析时，扩展才连接所选 AI 服务。分析会发送题目标题、链接、难度、语言及所选代码，不附带笔记或图片。详见[隐私政策](docs/PRIVACY.md)。

**卸载扩展或清除扩展存储会丢失本地知识库，当前版本暂无数据导出功能。** 自动保存失败时应先重试并确认保存成功，再离开页面。

## 支持范围

支持两站普通 `/problems/<slug>/` 题目路径及标准题解代码块。竞赛专用路径、部分非标准编辑器和文章组件暂不支持；网页结构变化可能影响捕获与加载。当前暂无单题删除或解法删除撤销功能。

CodeVault 是独立项目，与 LeetCode 无官方关联。
