# CodeVault

当前版本：**v0.1.0 阶段基线**（2026-09-26，Git 标签 `v0.1.0`）。用户已体验验收并确认保留此版，同时反馈仍有较多问题和 bug；此标签不代表无缺陷或完整验收通过。具体问题待后续整理，统一在 v0.2 迭代优化。现有自动化测试不能替代真实使用验收。

本地优先的算法知识管理 Chrome 插件。当前支持 LeetCode 题目识别、本地收藏、编辑器代码捕获、多版本解法保存与加载，以及 popup 收藏列表和页面悬浮面板；已支持 Markdown 题目笔记，已支持配置自己的 AI 接口分析代码。

打开 `/problems/<slug>/` 下的题目、题解或提交记录页面，展开面板即可查看标题、URL、难度和标签。中文站优先显示翻译名称。站内切题会更新信息，离开题目页会清空；请求失败可点击“重新识别”。关闭面板会取消题目识别请求。竞赛专用 URL 尚未适配。

点击“收藏题目”将当前元数据保存到本机；保存成功后显示“已收藏”，可通过“更新收藏”刷新元数据。两站同一题共用一条记录，标题与链接以最近一次主动保存为准。扩展弹窗展示按最近更新排序的收藏，支持刷新和打开题目；不联网也能读取已有收藏，但访问网站和识别题目需要网络。

数据保存在当前浏览器配置文件的扩展来源中，不使用 LeetCode 网页的 IndexedDB。重新加载扩展会保留收藏；当前支持删除单个解法，尚无题目删除、导出或云同步入口。

## 保存解法

1. 等待题目编辑器加载，将鼠标移入代码区，点击“添加至 CodeVault”；也可在面板中点击“读取当前代码”。
2. 检查代码预览，填写解法名称及可选备注，点击“保存解法”。语言从编辑器读取。
3. 在“我的解法”中展开条目查看代码、语言、备注及来源。每次重新读取并保存会创建一个独立版本；首次保存解法也会自动收藏题目。

保存的是读取时的代码快照。之后若修改网页编辑器，需要再次读取。切换题目或关闭面板会丢弃未保存的表单；已经提交的保存操作仍会完成。当前仅支持可编辑的 Monaco 代码区域，不采集只读题解文章、测试用例或整页文本，也不判断代码是否 AC。代码上限50万字符，名称100字符，备注5000字符。

数据库自动升级到版本3，保留已有收藏和解法。中文站真实编辑器捕获、保存、加载及 Ctrl+Z 撤销已验证；国际站受控测试通过，真实编辑器仍有此前 Cloudflare 人机验证导致的验证限制。

## 加载解法

解法详情中的“编辑信息”可修改名称、备注、来源类型（我的代码、参考题解、模板代码）和 HTTP/HTTPS 来源链接。代码和语言保持原快照；修改代码后请重新读取并保存新版本。来源标签由用户填写，不会自动导入题解文章。

点击“删除解法”并确认后永久删除该版本，题目收藏及其他版本保留。多标签页同时修改或删除同一版本时，旧表单会提示冲突；点击“刷新解法”重新读取（会放弃未保存的修改）。

在当前题目的“我的解法”中展开一个版本，点击“加载到编辑器”，将替换当前代码。点击代码编辑器后按 Ctrl+Z 可撤销这次加载。已保存的版本不会因此改变。

语言不匹配时先在 LeetCode 切换语言，再点击加载。语言校验使用 Monaco 的语言标识，不自动切换网页语言。编辑器只读、出现多个代码区、期间切题或输入新内容时会拒绝替换并提示重试。允许加载到空代码区；重复加载相同代码不新增撤销记录。

## 题目笔记

题目面板底部支持编辑和预览 Markdown，包含标题、列表、引用、代码块及 HTTP/HTTPS 链接。点击“保存笔记”保存到本机，每题一份，两站同题共用；首次保存会同时收藏题目。上限20000字符，清空内容后保存可清空笔记。

笔记采用手动保存，切题、关闭面板或刷新网页会丢弃未保存内容。保存失败或并发冲突时保留当前文字；可先复制，再使用“读取最新笔记”，放弃未保存修改前会确认。预览不执行 HTML、不加载外部图片。支持本地图片粘贴，算法示意图可作为图片粘贴保存。

在笔记编辑框中粘贴图片，会在光标或选中位置插入本地图片引用，点击“预览笔记”查看。支持 PNG、JPEG、WebP，每次一张；原图和转换后的 PNG 均不超过2MB，最多1600万像素，每篇最多5张、合计6MB。图片与文字一起手动保存，未保存前关闭面板会丢弃。删除 Markdown 中的图片引用后保存，会清理该附件。仅复制引用到另一题不会复制图片。

## AI 代码分析

从扩展设置页填写完整 HTTPS Chat Completions 地址、服务商模型 ID 和 API Key，点击“授权并保存 AI 配置”，允许浏览器访问该域名。DeepSeek 地址示例为 `https://api.deepseek.com/v1/chat/completions`，OpenAI 为 `https://api.openai.com/v1/chat/completions`。模型名称以账户可用模型为准；不自动检测模型。

题目面板点击“读取待分析代码”，检查快照、目标接口和模型，再点击“发送并分析代码”。请求只包含题目标题、链接、难度、语言与代码，不包含笔记或图片。结果包含思路、复杂度、面试表达和易错点，以纯文本显示，不执行 HTML、不自动保存。可手动复制到笔记。

每次最多50000字符，25秒超时，不自动重试；取消、关闭面板或切题会终止等待和请求，但服务商已产生的费用不保证取消。仅支持非流式 Chat Completions 与 HTTPS；不支持本地 HTTP、Responses 专用模型和图片分析。服务商可能需要不同参数，真实接口需自行验证。

Key 仅保存在当前浏览器扩展 IndexedDB，未加密、不云同步、不返回网页面板。每次保存配置需重新输入 Key；“清除 AI 配置”删除保存的 Key。已授权站点权限可在浏览器扩展设置中撤销。API 使用服务商账户额度，与聊天产品订阅无关。

已用模拟响应验证协议、鉴权失败、限流、超大/无效响应、取消、权限撤销和配置变化。原生权限弹窗与真实付费 API 尚未实测；自动化不发送真实 Key 或消耗额度。

## 开发环境与构建

需要 Node.js 22.12+（本项目使用 Node.js 24 验证）。

```powershell
npm ci
npm run dev
```

打开开发服务器的 `/popup.html` 或 `/options.html` 预览界面。Vite 开发服务器只用于页面预览，插件需要加载构建产物。

```powershell
npm run build
```

在 Chrome 的 `chrome://extensions` 开启开发者模式，选择“加载已解压的扩展程序”，指定本项目的 `dist` 目录。修改代码后重新构建、重新加载扩展，并刷新 LeetCode 页面。

## 验证

```powershell
npx playwright install chromium --no-shell
npm test
```

测试先执行 TypeScript 检查和生产构建，再检查 manifest 入口，以及在 Chromium 中实际加载扩展，验证 popup、设置页、悬浮面板开关、键盘关闭、窄屏布局和宿主样式隔离。页面测试使用 LeetCode URL 下的固定测试页面，不等同于真实 LeetCode 编辑器集成测试。截图输出到 `test-results/`。

存储测试使用真实浏览器 IndexedDB，验证来源隔离、首次保存、并发去重、更新时间、读写失败重试、事务回滚，以及浏览器重启后离线读取。测试仅在独立测试配置文件中运行。

解法测试覆盖150行完整代码（含中文、缩进、CRLF）、语言切换、多编辑器定向捕获、多版本、跨题清理、重试去重、题目与解法原子保存，以及版本1数据库迁移后原有收藏不丢失。

加载测试覆盖空代码区、重复加载、语言不匹配、只读、多编辑器、输入变化、模型切换、站内切题和写入失败。真实中文站另验证单次 Ctrl+Z 恢复加载前草稿。

题目识别测试另覆盖 URL 规范化、翻译回退、元数据校验、站内导航、慢请求返回时的竞态、失败重试及非题目页面。需要联网验证真实页面时运行 `npm run test:live`；这会在临时浏览器配置文件中访问两站公开的“两数之和”题目，检查识别、收藏、代码保存、加载和撤销，不提交或运行代码。网络、编辑器加载或站点人机验证可能使该测试失败，因此未纳入默认测试。可设置 `$env:CODEVAULT_LIVE_HOST='leetcode.cn'` 或 `'leetcode.com'` 单独验证某站。

Windows 若下载版 Chromium 出现“并行配置不正确”的系统启动错误，可使用已安装的 Edge 运行同一测试：

```powershell
$env:CODEVAULT_BROWSER_CHANNEL = 'msedge'
npm test
```

本轮在 Edge（Chromium）上通过验证；Playwright 固定为 1.56.1，依赖版本由 `package-lock.json` 锁定。

## 目录

- `src/popup`、`src/options`：插件页面。
- `src/content`：注入 LeetCode 的 React 悬浮面板，CSS 隔离于 Shadow DOM。
- `src/background`：Manifest V3 service worker。
- `src/editor`：MAIN world 的 Monaco 读取与可撤销加载桥接，不接触扩展存储。
- `src/components`：共享 React 组件。
- `src/platforms`：平台适配器接口、题目数据类型及 LeetCode 元数据获取。
- `src/database`：IndexedDB题目与解法存储、消息类型、客户端和输入校验。
- `src/ai`：AI 配置、本地 Key 存储、Chat Completions 请求与取消处理；`src/utils` 为预留目录。
- `public/manifest.json`：插件权限与入口声明。
- `scripts/build.mjs`：依次构建页面、content script、background 与 editor 桥接。
- `docs`：产品需求、架构、设计和界面参考。

Markdown 预览使用 react-markdown 10.1.0；Zustand、shadcn/ui 将在对应功能需要时接入。
