# CodeVault 产品需求文档 v0.1

## 产品定位

CodeVault 是一个 Local-first 的算法知识管理 Chrome 插件。

它不是刷题平台，而是增强 LeetCode 等网站，帮助用户沉淀自己的算法资产。

核心流程：

    刷题
    ↓
    保存解法
    ↓
    添加笔记
    ↓
    AI分析
    ↓
    形成个人算法库

## 核心功能

### 1. 题目收藏

自动保存：

-   标题
-   URL
-   难度
-   标签

### 2. 代码捕获

鼠标移动到代码区域：

显示：

    + 添加至CodeVault

保存：

-   自己AC代码
-   优秀题解
-   模板代码

### 3. 解法管理

支持多个解法：

例如：

    Two Sum

    HashMap一次遍历

    暴力枚举

    面试表达版

每个解法支持：

-   名称
-   代码
-   语言
-   来源
-   备注

### 4. 解法覆盖

用户点击自己的解法：

直接在当前LeetCode编辑器中替换代码。

用户无需离开页面。

### 5. 笔记

每道题支持：

-   Markdown
-   图片
-   算法示意图

### 6. AI助手

用户配置自己的API。

AI分析：

-   思路
-   复杂度
-   面试表达
-   易错点

## 非目标

暂不开发：

-   在线判题
-   用户系统
-   云同步
-   社区
