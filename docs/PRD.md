# CodeVault 产品需求文档 v0.1

## 产品定位

CodeVault 是一个 Local-first 的算法知识管理 Chrome 插件。

它不是刷题平台，而是增强 LeetCode 等网站，帮助用户沉淀自己的算法资产。

核心流程：

    刷题
    ↓
    保存解法
    ↓
    添加笔记
    ↓
    AI分析
    ↓
    形成个人算法库

## 核心功能

### 当前交付范围（Milestone 2 + 本地题目收藏）

已支持 LeetCode 中文站和国际站普通题目 URL 的识别。在展开的面板内展示标题、规范化题目链接、难度和标签；中文站优先展示中文名称。站内切换题目时刷新，离开题目页时清空。提供加载提示、10秒超时和失败重试。

已支持主动收藏题目元数据、更新收藏和在 popup 查看本地收藏；刷新页面或重启浏览器后可恢复收藏，收藏列表可离线读取。浏览题目本身不会自动写入知识库。尚未实现代码捕获、解法存储、笔记或解法覆盖。竞赛专用路径暂不支持。

### 1. 题目收藏

点击“收藏题目”时自动获取并保存：

-   标题
-   URL
-   难度
-   标签

同一题在中文站和国际站共用一条记录，重复收藏更新元数据，不新增副本。列表按更新时间倒序展示。保存失败应明确提示，并保留之前的数据；只有事务成功后才能展示保存成功。

### 2. 代码捕获

鼠标移动到代码区域：

显示：

    + 添加至CodeVault

保存：

-   自己AC代码
-   优秀题解
-   模板代码

### 3. 解法管理

支持多个解法：

例如：

    Two Sum

    HashMap一次遍历

    暴力枚举

    面试表达版

每个解法支持：

-   名称
-   代码
-   语言
-   来源
-   备注

### 4. 解法覆盖

用户点击自己的解法：

直接在当前LeetCode编辑器中替换代码。

用户无需离开页面。

### 5. 笔记

每道题支持：

-   Markdown
-   图片
-   算法示意图

### 6. AI助手

用户配置自己的API。

AI分析：

-   思路
-   复杂度
-   面试表达
-   易错点

## 非目标

暂不开发：

-   在线判题
-   用户系统
-   云同步
-   社区
