# CodeVault 产品需求文档 v0.1

## 产品定位

CodeVault 是一个 Local-first 的算法知识管理 Chrome 插件。

它不是刷题平台，而是增强 LeetCode 等网站，帮助用户沉淀自己的算法资产。

核心流程：

    刷题
    ↓
    保存解法
    ↓
    添加笔记
    ↓
    AI分析
    ↓
    形成个人算法库

## 核心功能

### 当前交付范围（代码保存与加载流程）

已支持 LeetCode 中文站和国际站普通题目 URL 的识别。在展开的面板内展示标题、规范化题目链接、难度和标签；中文站优先展示中文名称。站内切换题目时刷新，离开题目页时清空。提供加载提示、10秒超时和失败重试。

已支持主动收藏题目元数据、更新收藏和在 popup 查看本地收藏；刷新页面或重启浏览器后可恢复收藏，收藏列表可离线读取。浏览题目本身不会自动写入知识库。

已支持从可编辑的 Monaco 区域读取完整代码与语言，命名后保存，附加可选备注；同题支持多个独立版本，并自动记录编辑器来源 URL。首次保存解法会原子地创建题目收藏，失败时两者均不写入。列表支持展开查看代码和备注，并将同题、同语言解法加载回当前编辑器。支持修改解法名称、备注、来源类型和链接，以及确认后永久删除单个解法。已支持 Markdown 题目笔记；已支持配置自己的 AI 接口分析代码；尚未实现第三方题解文章捕获。竞赛专用路径暂不支持。

### 1. 题目收藏

点击“收藏题目”时自动获取并保存：

-   标题
-   URL
-   难度
-   标签

同一题在中文站和国际站共用一条记录，重复收藏更新元数据，不新增副本。列表按更新时间倒序展示。保存失败应明确提示，并保留之前的数据；只有事务成功后才能展示保存成功。

### 2. 代码捕获

当前实现范围：普通题目页面的可编辑 Monaco 代码区，读取时生成快照，保存前展示预览。语言自动识别；空代码、超长代码、未就绪或无法唯一定位的编辑器应明确报错，不从可见行拼接代码。

鼠标移动到代码区域：

显示：

    + 添加至CodeVault

保存：

-   自己AC代码
-   优秀题解
-   模板代码

### 3. 解法管理

来源可标记为我的代码、参考题解或模板代码，链接仅允许 HTTP/HTTPS 且不包含账号密码。代码和语言保持创建时的快照，更改代码通过保存新版本完成。删除保留父题目和其他版本；并发修改采用版本校验，过期操作提示刷新，不覆盖更新的数据。失败保留编辑表单，刷新会放弃未保存的修改。

支持多个解法：

例如：

    Two Sum

    HashMap一次遍历

    暴力枚举

    面试表达版

每个解法支持：

-   名称
-   代码
-   语言
-   来源
-   备注

### 4. 解法覆盖

当前已实现：在解法详情点击“加载到编辑器”替换当前代码，保持可通过 Ctrl+Z 撤销。按钮旁明确显示替换含义。语言不匹配时提示用户先在网页切换，不自动更改网页语言。切题、模型或内容变化、只读和多个候选编辑器时拒绝加载；成功加载不会修改已保存版本。

用户点击自己的解法：

直接在当前LeetCode编辑器中替换代码。

用户无需离开页面。

### 5. 笔记

当前已交付每题一份 Markdown 笔记、编辑/预览和手动保存，最多20000字符。首次保存同时收藏题目，已有收藏元数据保持不变。两站同题共享笔记；并发冲突和保存失败保留草稿，读取最新版本前确认放弃修改。切题、关闭面板或刷新时未保存内容丢弃，界面明确提示。HTML 不渲染；已支持本地图片粘贴和预览，算法示意图可作为图片粘贴保存。

每道题支持：

-   Markdown
-   图片
-   算法示意图

笔记图片：用户在编辑框粘贴 PNG/JPEG/WebP，解码后转为 PNG，插入当前光标或替换选区。每次一张，输入与输出均限2MB、解码图片限1600万像素；每篇最多5张、总计6MB。图片与文字一起保存、一起回滚，删除引用后保存清理附件；放弃草稿不产生孤立图片。跨题不共享图片，外部图片不自动下载。

### 6. AI助手

用户配置自己的API。

当前交付：设置完整 HTTPS `/chat/completions` 地址、模型与 API Key，保存时申请对应域名权限。代码分析先读取当前编辑器快照，显示目标接口与模型，用户点击发送后传输题目标题、链接、难度、语言和代码。最多50000字符，25秒超时，支持取消；切题、关闭面板丢弃结果并终止请求。结果纯文本展示，不自动保存，不判定 AC。笔记和图片不发送。Key 本地未加密保存、不回显，支持清除；未配置时引导前往设置。

AI分析：

-   思路
-   复杂度
-   面试表达
-   易错点

## 非目标

暂不开发：

-   在线判题
-   用户系统
-   云同步
-   社区

## v0.2 Round 1（2026-09-27）

以 `CodeVault_PRD_v0.2.md` 为最新需求，按功能分轮交付；v0.1.0 标签继续作为历史基线。

- 默认打开收藏题库，popup 与 LeetCode 面板共享题库组件；提供设置入口及“查看当前题目”。
- 支持按题名、标签、解法名称搜索，展示解法数量、笔记状态与最近访问；最近列表最多三题。
- 选择收藏题优先使用当前 LeetCode 标签页；从 popup 进入时复用已有 LeetCode 标签页，没有则新建。跳转完成自动展开对应题目详情。
- 详情提供“返回题库”，保留搜索和列表滚动位置；SPA 切题继续跟随网页，完整页面跳转恢复面板状态。
- 收藏时间从旧记录创建时间迁移；历史未知访问时间保持空值。浏览未收藏题目不会自动收藏。
- 本轮不代表 v0.2 整体验收完成。解法摘要、覆盖确认、题解捕获、笔记块编辑及 AI Provider/流式分析按后续轮次实现。

## v0.2 Round 2（2026-09-27）

- 解法保存名称可留空；后台在同一事务内生成“解法 N”，避开当前题目已有名称。并发保存独立命名，同一请求重试不重复创建。
- 保存表单只显示语言和代码字符数；解法列表显示名称、语言、日期、来源和加载入口，不再展示完整代码。展开可查看备注、来源及管理操作。
- 当前编辑器有非空且不同的内容时，先确认覆盖。取消不改代码；确认期间代码、模型、语言或题目发生变化则拒绝写入。相同代码不新增撤销记录，空编辑器可直接加载；成功提示保留六秒。
- 支持两站普通题目 `/solution/`、`/solutions/` 页面中的 `pre > code` 文章代码块 Hover 捕获，完整保留代码并标记为参考题解、保留文章 URL。提交保存时自动收藏父题目。语言从代码块标记读取，无法识别时需手动选择。
- 捕获入口保持面板关闭时显示；自定义虚拟化文章代码控件、非标准代码块仍需后续适配。普通题目描述中的代码示例不作为文章捕获入口。
- 修复非题目页进入题目时的 SPA 详情同步；popup 复用标签页优先当前窗口，面板操作优先自己的标签页。

## v0.2 Round 3（2026-09-27）

- 题目笔记改为普通文字与图片块，不再提供 Markdown 源码编辑或额外预览。文字支持换行、添加段落及空段落退格删除。
- 图片支持粘贴、拖入笔记区域和文件上传，插入后直接原位显示；在文字选区插入会保留前后文字，光标移到图片后的文字块。
- 停止输入750ms后自动保存；返回题库、关闭面板、切题、页面隐藏或离开时提交最新快照。显示待保存、保存中、已保存和失败状态。
- 冲突和存储失败暂停自动重试，保留当前页面会话的草稿；提供重试保存及确认放弃后读取最新内容。正常刷新保存流程有回归覆盖，浏览器强制终止或存储失败后强行刷新不承诺恢复尚未提交的内容。
- 图片删除需确认，并提供10秒撤销；保留单张2MB、每篇5个附件/合计6MB、文字20000字符限制，块结构最多100项。
- v0.1 Markdown 与本地图片原地迁移，标题、列表和代码转换为普通文字，本地图片转换为图片块。原文与原附件保存在只读 legacy 备份中，后续编辑不覆盖备份；外部图片不发起网络请求。

## v0.2 Round 4（2026-09-28）

- AI 设置提供 DeepSeek、OpenAI、Anthropic Claude 预设及模型选择；普通模式无需填写 URL。自定义 Chat Completions 地址和模型放在高级设置。
- 用户点击“测试连接”后向所选服务发送一条短消息，显示测试中、成功或失败；验证有效文本响应，最多等待25秒。测试不包含题目和代码，可能产生服务商费用，不自动保存配置。
- 未修改配置时可测试已保存的密钥；新配置需要输入密钥。更换服务商清空输入，保存配置仍需重新输入。旧配置按自定义模式读取，原地址、模型、密钥和版本不变。
- 密钥仅在本机扩展设置库中保存，不回显、不云同步、不上传 CodeVault 服务器，默认不包含在数据导出中。Claude 分析使用原生 Messages 协议。
- 流式输出、Markdown 分析展示、精炼提示词和按解法保存分析仍属于 Round 5。

## v0.2 Round 5（2026-09-28）

- AI 分析新增“分析对象”：选择已保存解法或当前编辑器临时快照；读取后展示语言、字符数、服务商接口和模型摘要，不展示完整代码。发送始终由用户点击触发。
- 分析支持流式 Markdown，边生成边显示标题、列表、强调和代码格式；不执行 HTML、不加载外部图片、链接只显示文字。停止生成保留已收到的内容，标明不完整且不能保存。
- 默认提示词要求150至300字，按思路、复杂度、关键点、易错点组织，面试表达可选；不重复代码或完整题目。字数是生成要求，不作强制截断；输出上限1200 tokens。
- 完整生成后支持重新生成；选择已保存解法时可“保存分析”，再次保存需确认替换原分析。当前编辑器临时分析若要保存，需先保存为解法再选择该解法分析。
- 分析作为 Solution 附属字段保存在本机，展开解法可复习；刷新和重启浏览器后仍可读取。保存校验版本，已修改或删除的解法不能被旧结果覆盖。失败、停止、流截断均不自动保存。
- 真实服务输出质量与实际账户网络仍待用户验收；Round 6 统一视觉和综合验收未完成。

## v0.2 Round 6（2026-09-28）

- 统一题库、详情、popup和设置页视觉；采用轻边框、柔和强调色、小图标和较少的深色块，标题、列表和表单层级一致。
- 详情返回入口移入固定顶栏；长内容在400px面板内部滚动，窄屏保持导航可用。主页不显示返回按钮。
- 设置引导同步普通图文笔记和流式分析能力；明确主动连接测试也会调用服务商。
- 修复覆盖分析确认期间重复点击原保存按钮可能绕过专用确认按钮的问题。
- 开发交付与用户发布验收分开记录，详见 ACCEPTANCE_v0.2.md；暂不更新安装包版本或创建 v0.2 标签。

## v0.2 用户验收修正：笔记图片（2026-09-28）

以本次用户反馈为准：笔记只保留一个思路文字框，不再提供添加段落。已有非空段落按顺序合并显示，空占位段落忽略，不丢弃旧文字。

图片通过粘贴、拖放或上传加入文字框下方的缩略图列表，不拆分文字或创建新文字框。悬停或键盘聚焦图片时右上角显示 ×，点击直接删除并自动保存；十秒撤销保留。点击缩略图以屏幕中央弹窗查看，支持关闭按钮、Esc 和背景点击。

扩展工具栏、扩展管理页、页面悬浮按钮、标题与设置页品牌采用用户提供的第二张图，保持原图内容，仅生成所需尺寸。
