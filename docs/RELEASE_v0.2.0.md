# CodeVault v0.2.0

发布日期：2026-09-28。用户确认当前版本发布为v0.2.0，保留v0.1.0历史基线。

## 更新内容

- 默认收藏题库、搜索、最近访问、点击跳题和返回状态保留，跟随 LeetCode SPA 切题。
- 多版本解法摘要、自动命名、标准题解代码块捕获；加载不同代码前确认，保留 Ctrl+Z 撤销。
- 普通文字笔记自动保存；仅一个思路输入框，图片下排缩略图，悬停×删除、十秒撤销、点击居中预览。旧笔记文字和图片保留。
- DeepSeek、OpenAI、Anthropic Claude 预设、模型选择与最小请求连接测试；自定义兼容接口位于高级设置。
- AI流式Markdown分析、停止生成、精炼提示词、按解法保存、覆盖确认和版本冲突保护。
- 统一400px面板、固定顶部导航、窄屏适配、popup与设置页视觉，采用用户提供的新图标。

## 安装与升级

本次发布为源代码标签及可加载的扩展ZIP，不是Chrome应用商店发布。

本地安装包：`releases/CodeVault-v0.2.0.zip`。解压到固定目录，在浏览器扩展管理页开启开发者模式，选择“加载已解压的扩展程序”，指向包含manifest.json的目录。

已有开发版建议继续使用原来的dist目录：更新代码后运行npm ci及npm run build，在扩展管理页点击重新加载，再刷新LeetCode。保持原浏览器配置、扩展安装和目录，避免删除扩展导致本地数据丢失。数据库仍为codevault v5和codevault-settings v1，不新增清库或数据重置。
