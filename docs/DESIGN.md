# CodeVault UI设计 v0.1

## 当前实现（2026-09-26）

基于 HTML Demo 的白色面板、20px 圆角、浅灰信息卡和深色按钮实现基础界面。

- popup：精简产品介绍、打开 LeetCode、我的收藏和设置页入口。收藏列表按最近更新排序，可刷新或点击题目返回网站；具备空列表、加载和错误提示。
- 网页面板：默认仅显示右下角火箭按钮，点击展开；支持关闭按钮及 Escape 收起。
- 面板适应窄屏，长内容可滚动，按钮具备键盘焦点样式。
- 题目区域展示加载提示、非题目页引导、错误提示和“重新识别”按钮；成功后显示标题链接、难度徽标、标签和规范化 URL。
- 简单、中等、困难使用绿色、黄色、红色徽标，并保留文字标识。无标签时显示“暂无标签”。切题时撤下旧题信息，避免混淆。
- 识别后读取收藏状态：未收藏显示“收藏题目”，成功后显示“已收藏 · 保存在本机”和“更新收藏”。读取和写入期间禁用保存按钮；失败提示可重试，不伪造成功状态。
- 代码区悬浮显示“添加至 CodeVault”；面板提供“读取当前代码”。读取成功展示语言、字符数、只读代码预览、解法名称和可选备注，明确保存的是快照。
- 保存期间禁用重复操作。成功后显示版本名称，并更新题目收藏状态与解法列表；失败时保留表单以便重试。
- 解法列表按创建时间倒序，展开可查看完整代码、语言、备注、保存时间及来源链接，并提供“加载到编辑器”按钮。旁边提示替换当前代码和 Ctrl+Z 撤销方式。
- 加载中禁用重复操作，成功显示版本名称；语言不匹配提示在网页切换语言，模型或代码已变化时提示重试。已保存版本保持原样。
- 解法详情提供“编辑信息”，表单包含名称、备注、来源类型和来源链接，支持保存或取消；代码和语言不可修改。“删除解法”展开包含版本名称的永久删除确认，支持取消。
- “刷新解法”可恢复最新列表，编辑期间提示将放弃未保存修改。并发冲突提示刷新重试，存储失败保留表单。编辑或删除确认期间禁止其他版本的管理操作。
- 设置页提供 AI 接口、模型及 API Key 配置，保存时申请对应域名权限；支持清除配置，不回显已保存 Key。
- 题目笔记位于解法列表下方，提供编辑/预览切换、字符计数、未保存提示和“保存笔记”。加载期间禁用编辑，错误保留内容并显示重试入口。
- “读取最新笔记”在有未保存内容时展示放弃修改确认；并发冲突提示先复制内容。预览包含标题、列表、引用和代码块；本地附件显示图片，缺失或外部图片显示占位说明。

## 设计目标

AI 设置显示完整接口 URL、模型、密码输入框和已配置状态，保存成功清空 Key 输入。页面说明数据发送范围和本地存储方式。面板在笔记下方提供 AI 分析区：读取快照 → 查看代码、接口及模型 → 主动发送。处理中可取消，错误可重试；结果以纯文本展示，提示未运行验证且不自动保存。

笔记编辑框上方说明支持的图片格式、单张和每篇大小限制；粘贴后显示“图片已插入，请保存笔记”。预览图片按面板宽度缩放。图片处理或保存失败显示错误，保留原文字和草稿图片。

CodeVault 是轻量Chrome插件。

## UI原则

-   不打扰刷题
-   操作路径短
-   信息清晰
-   本地工具感

## v0.2 Round 1 设计增量（2026-09-27）

- LeetCode 面板宽度调整为 400px，小屏仍受视口宽度约束；标题、设置和关闭操作位于统一顶栏。
- 主页包含当前题目入口、搜索框、最近访问和全部收藏；收藏采用轻分隔线，展示难度、解法数量、笔记状态、标签和可用的访问时间。
- 搜索无匹配、无收藏、读取失败和跳转失败分别给出提示。加载时保留已显示列表；跳转期间避免重复点击。
- 详情顶部显示“← 返回题库”；主页列表内部滚动，返回恢复原位置和查询。关闭再开保持当前视图，同一浏览器会话内完整跳转恢复面板。
- popup 顶部提供同样的标题与设置入口，正文复用题库；底部提供打开 LeetCode 的入口。
- 详情中的旧解法、笔记和 AI 交互暂时保留，按后续轮次逐步替换；本轮仅完成导航外壳和收藏主页样式。

## v0.2 Round 2 设计增量（2026-09-27）

- 解法名称在列表首行；语言、日期、来源和加载入口在下一行。备注、来源链接、编辑与删除操作保留在可展开区域，移除代码全文。
- 保存表单名称为可选，提示留空自动命名；保留语言、字符数和备注。参考代码提供语言选择，避免把无法识别的语言静默保存为错误语言。
- 加载不同代码时展示面板内“覆盖代码确认”，提供取消加载/继续加载。说明可能有未保存内容，不声称能判断 LeetCode 的提交或保存状态。
- 成功加载显示六秒绿色轻提示，保留 Ctrl+Z 撤销说明。其他读取/保存错误继续可重试。
- 文章 Hover 按钮复用已有捕获入口；提交保存前只建立本地快照，不提前产生收藏或解法记录。

## v0.2 Round 3 设计增量（2026-09-27）

- 笔记区直接显示普通文字段落与图片，删除编辑/预览切换以及常驻保存按钮。文本框随内容增长，保持普通字体与轻边框。
- 标题旁以轻量文字显示待自动保存、正在保存、已保存；存储失败显示错误和重试入口。读取最新笔记在有草稿时需明确确认放弃。
- 粘贴图片替换当前选区，保留前后文字；上传复用最近的文字插入位置，未选择位置时追加到末尾。拖入笔记区也可插图。
- 提供上传图片、添加段落；图片原位显示，删除需确认并可在十秒内撤销。
- 迁移笔记显示原文与附件已备份的提示。原文不作为 Markdown 编辑界面重新暴露。

## v0.2 Round 4 设计增量（2026-09-28）

- 设置页先选 AI 服务，预设模式显示模型下拉框和密码输入框。自定义选项展开高级设置，显示完整接口地址与模型名称。
- 测试连接、授权并保存、清除配置为独立操作。测试中禁用表单，按钮显示“测试中…”，结果使用状态提示，错误使用 alert；修改输入清除过期结果。
- 明示测试会调用服务商并可能计费，测试不会保存配置。已保存密钥不回显；修改配置需重新输入，切换服务商清空密钥输入。
- 旧自定义配置自动显示高级字段，已有数据可继续使用。

## v0.2 Round 5 设计增量（2026-09-28）

- AI 区先选择分析对象，再读取快照、明确发送；摘要显示解法名、语言和字符数，去除常驻全文代码框。
- 输出原位渲染 Markdown，生成时显示“停止生成”；停止或异常保留部分内容和错误提示，不显示可保存按钮。
- 完成后提供“重新生成”，已保存解法提供“保存分析”；保存成功给出反馈，覆盖已有分析需确认。临时编辑器分析明确说明保存路径。
- 已保存分析在解法展开区展示，使用相同的标题、列表和代码排版。分析区不显示外部图片，不执行 HTML。
- 视觉统一仍安排在 Round 6；本轮沿用现有面板和按钮样式。

## v0.2 Round 6 设计增量（2026-09-28）

- 共享浅紫强调色、深灰正文、柔和灰色辅助文字；正文区域白底，分区用细分隔线，减少套叠卡片和大块深色按钮。
- 以 </> 品牌标记替换火箭 emoji，导航采用本地SVG并保留按钮可访问名称与焦点环。
- 400px面板顶部固定返回/品牌/设置/关闭，主页隐藏返回；小屏宽度受视口限制。表单操作可换行，长题名、标签和解法名允许折行。
- 设置页调整为较宽的阅读区域，模型与密钥表单、连接反馈与面板保持相同圆角和颜色体系。
- Markdown标题使用紧凑字号，列表不继承解法条目的分隔线；图文笔记继续原位编辑。

## 笔记图片验收修正（2026-09-28）

- 单一自适应高度的思路输入框；移除添加段落与图片后新输入框。
- 图片下排，缩略图96×80px，自适应换行；悬停/焦点显示右上角删除×，触屏常显。点击直接删除，保留十秒撤销。
- 点击图片在屏幕中央打开带暗色遮罩的大图，受视口宽高限制，支持关闭按钮、背景点击及Esc，不影响面板开关。
- 用用户提供的图替换 </> 品牌与扩展图标。
